# **Blog Dashboard**

A **React.js + TypeScript** blog management dashboard with a **dark theme**, built using **Bootstrap & CSS**. It allows users to create, edit, delete, and manage blog posts efficiently.

## **Features**
### 📌 **All Posts Page**
- Contains **tabs** for:  
  - **Published** (Live posts)  
  - **Drafts** (Unpublished posts)  
  - **Trashed** (Deleted posts)  
- Displays a **table** with:
  - **Title, Category, and Actions** (Edit & Delete)
- Actions:
  - **Edit** → Navigates to the edit page with editable fields (**Title, Content, and Category**), along with **Publish & Draft buttons**.
  - **Delete** → Moves the post to the **Trash tab**.

### 📝 **Add New Post Page**
- A form with:
  - **Title**
  - **Content**
  - **Category**
  - **Publish & Draft buttons**  

### 👀 **Preview Page**
- Displays **Published** posts.
- Includes **Pagination** for better navigation.

## **Installation & Setup**
1️⃣ **Clone the repository**  
```sh
git clone https://github.com/Aul-rhmn/blog-dashboard.git
cd blog-dashboard
```

2️⃣ **Install dependencies**  
```sh
npm install
```

3️⃣ **Run the project**  
```sh
npm start
```
